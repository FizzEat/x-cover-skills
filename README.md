# X 封面图 Skill

分析 X 榜单长文榜 **3,917 篇长文、3,535 张封面**，把高收藏封面拆成 **11 个视觉家族、100 个风格 skill**，每个 skill 自带 PGVP 结构拆解、可填空英文提示词、中英区标题排版建议，以及从 AIGC 灵感台匹配的风格增强词。

适用于 Claude Code、Codex 等支持 `SKILL.md` 的 Agent，也可以直接当提示词库翻着用。

## 能做什么

- 丢一篇长文标题给 Agent：“帮我做个 X 长文封面” → 路由 skill 推荐 3 个风格并直接给提示词
- 指定风格：“用 x-cover-stipple-abyss 给这篇文章出图” → 稳妥 / 强钩子 / 反差 3 个版本
- 不装 skill，直接打开 [CATALOG.md](CATALOG.md) 或 [catalog.json](catalog.json) 复制模板

## 安装

```bash
git clone https://github.com/FizzEat/x-cover-skills.git
```

```bash
cd x-cover-skills && ./install.sh
```

默认只装路由 skill `x-cover` + 你选的家族，避免 100 个 skill 描述全部挤进上下文：

```bash
./install.sh --family A,C,I
```

```bash
./install.sh --all
```

装到 Codex：`./install.sh --target ~/.codex/skills --all`。

## 一个 skill 长什么样

```text
skills/x-cover-stipple-abyss/SKILL.md
├─ 一句话用途 / 适用分类 / 区域倾向 / 画幅
├─ 工作流（读文章 → 填变量 → 出 3 个版本 → 按模型补参数）
├─ PGVP 五段：Identity / Spatial / Visual State / Material / Lighting
├─ 英文提示词模板 + 变量填写表
├─ 中文区 / 海外区标题排版建议
├─ 灵感台风格增强词（6 条可叠加关键词）
└─ 避坑
```

## 三条结论

1. **中文区卖“你能拿到什么”，海外区卖“你会变成谁”**：前者文字占 40%~60%、直接摆交付物，后者几乎无字、靠隐喻。
2. **AI 只出底图，文字后期排**：所有模板都预留标题区。
3. **一张封面只承诺一件事**。

## 二次开发

```text
specs/families.py   11 个家族的排版建议与避坑
specs/skills.py     100 个风格定义（改这里加风格）
build.py            生成 skills/、catalog.json、CATALOG.md
data/enrich.json    灵感台匹配结果快照
data/stats.json     长文榜聚合统计
```

改完定义后重新生成：

```bash
python3 build.py
```

有自己的 AIGC 灵感台 `data.js` 时，可重新抽取风格增强词：

```bash
python3 build.py --lingan /path/to/灵感台/data.js
```
